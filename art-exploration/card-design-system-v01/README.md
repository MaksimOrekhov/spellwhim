# Class card identity — experimental control art v0.1

These three original fan-art drafts are a small visual control set for the class card identity exploration. They were generated with the built-in ImageGen tool using the user-provided Varian and Jaina portraits as style and lighting references only.

| File | Subject | Status |
|---|---|---|
| `warrior-defensive-parry.png` | Steel parry with bronze details and amber sparks | Experimental, not approved |
| `mage-fireball.png` | Orange-gold fireball with violet arcane accents | Experimental, not approved |
| `mage-arcane-bolt.png` | Sapphire and amethyst arcane bolt | Experimental, not approved |

No characters, lettering, UI, card frame, or class emblem are included. These files are outside `src/assets/art/` and are not connected to the game. Review the direction before using it as a basis for further card art.
