# Class card identity — experimental control art v0.1

These three original fan-art drafts are a small visual control set for class identity. They have been revised to use neutral abstract backgrounds, following the rule that ability art is class/mechanic-driven and reusable across adventures. They are not approved and are not connected to the game.

| File | Subject | Background | Status |
|---|---|---|---|
| `warrior-defensive-parry.png` | Steel parry with bronze details and amber sparks | Neutral charcoal and slate | Experimental, not approved; neutral-background revision |
| `mage-fireball.png` | Orange-gold fireball with violet arcane accents | Abstract indigo and violet magic | Experimental, not approved; neutral-background revision |
| `mage-arcane-bolt.png` | Sapphire and amethyst arcane bolt | Abstract indigo magic | Experimental, not approved; neutral-background revision |

No lettering, UI, card frame, or class emblem is included. These files are outside `src/assets/art/` and are not connected to the game. Review the direction before using it as a basis for further card art.
