# Combat Foundations Review v1 — воспроизводимый пакет

Отчёт: [`docs/design/combat-foundations-independent-review-v1.md`](../../design/combat-foundations-independent-review-v1.md). База — `main` @ `8d4ffd6`. Игровой код, баланс и `main` не изменялись; пакет читает `src/game/*.ts` через Vite SSR (как остальные скрипты проекта) и ничего не пишет вне `docs/data/combat-foundations-review-v1/results/`.

## Что внутри

| файл | назначение |
|---|---|
| `lab/engine.mjs` | Стенд: правила (рука/добор/мана/сброс/срок жизни брони) поверх настоящих `createBattle`/`playCard`/`endTurn`; перебор хода (все последовательности карт на копиях состояния), бот-«личности» `tempo` / `balanced` / `careful` (цена потерянного здоровья λ 0,45 / 1,0 / 2,4), метрики решений |
| `lab/extras.mjs`, `lab/extras2.mjs` | **Модели** механик, которых нет в движке: Резерв, Клятва, Приёмы героев, Связка (потолок), Срыв замаха, сдвиг порога фазы, Ослабление + «Добить», Строй, предел брони. Хуки правят только копии состояния |
| `lab/experiments.mjs` | Определения экспериментов (`baseline`, `grid`, `factors`, `pressure`, `length`, `extras`, `iso`, `armor`, `mech2`, `pace`, `phase2`, `r0fam`, `final`, `final2`) и трёх концептов `A`/`B`/`C` |
| `lab/run.mjs` | Запуск: `node docs/data/combat-foundations-review-v1/lab/run.mjs <эксперимент> --runs 200 --workers 11` → `results/<эксперимент>.json` и `.md` |
| `lab/static.mjs` | Точные (без симуляции) факты: что угрожает в Секторе I; случайная рука стартовой колоды; максимум брони одному герою за ход → `results/static.*` |
| `lab/interp.mjs` | Сравнение вариантов **при равной сложности**: линейная интерполяция масштаба урона до заданной доли побед `balanced` |
| `lab/tables.mjs` | Сводные таблицы отчёта → `results/tables.md` |
| `lab/examples.mjs` | Печатает реальные ходы из движка (рука, намерение, граница «урон врагу ↔ потеря HP», выбор каждого бота) — из него взяты примеры в отчёте |
| `lab/run-all.sh` | Весь набор (≈ час на 12 ядрах) |
| `results/*.json` | Полные агрегаты по ячейкам, включая метрики решений и разбивку по врагам |

## Как запускать (из корня репозитория, зависимости игры уже установлены)

```sh
node docs/data/combat-foundations-review-v1/lab/static.mjs
node docs/data/combat-foundations-review-v1/lab/run.mjs baseline --runs 200
node docs/data/combat-foundations-review-v1/lab/interp.mjs mech2 0.6
node docs/data/combat-foundations-review-v1/lab/examples.mjs B 1 7 3 0.75
node docs/data/combat-foundations-review-v1/lab/tables.mjs
```

## Метрики решений

На каждом ходу, где объявлен удар по героям, стенд перебирает **все** допустимые последовательности карт и считает для каждой: урон врагу, потерю здоровья героев от удара, победу/смерть.

- **свободная защита** — есть линия, которая и бьёт максимально, и теряет минимум HP (выбора между защитой и атакой нет);
- **нет безопасной линии** — любая линия теряет HP (выбора тоже нет: терять придётся);
- **спорный ход** — остальные: безопасность реально стоит урона;
- **расхождение ботов** — три бота с разной ценой здоровья выбирают разные по итогу линии;
- **цена безопасности** — урона врагу отдано ради минимальной потери HP.

## Честные границы

- Бот — перебор одного хода с эвристикой оценки; он не планирует на несколько ходов, не оценивает HP как бюджет всего похода, не человек.
- Цепочки S3/S4 не содержат наград, улучшений, лечения и событий; реальный поход сильнее. Числа сравниваются **между ячейками**, а не как прогноз выживаемости.
- 200 цепочек на ячейку; общие seed между ячейками. При 50 % побед стандартная ошибка ≈ 3,5 пп; разницы в 1–3 пп — шум.
- Модели механик — приближения (например, «Связка» дана как верхняя граница: бонус на всех картах с числом).
- В ходе работы найдена и исправлена ошибка стенда: «необязательные» действия (Клятва, Приёмы) ошибочно считались обязательными в конце хода. Результаты с этими механиками посчитаны **после** исправления (`mech2`); `extras` и `iso` пересчитаны без них.
- Лорные, художественные и интерфейсные вопросы здесь не рассматриваются.
