## Исправление shuffle без порчи истории

[audit.mjs](../../research/gdd-v2/audit.mjs) получает код Claude из точного commit, перенаправляет вывод в **новые** каталоги, затем исполняет:

- power-curve, 50 seed на конфигурацию/врага, исходный sort и Fisher–Yates;
- long-run, **только путь rec11**, 80 seed, все 40 deck/heal/strategy/skip-конфигураций; оба множителя обычных врагов 1/1 и 0,75/0,8; исходный sort и Fisher–Yates.

В исправленном варианте единственное изменение исследовательской логики — замена `sort(() => rand() - 0.5)` на seeded Fisher–Yates. Общие игровые модули, рейтинги и политики не меняются. Исходные sort-варианты **точно воспроизвели все сохранённые строки выбранных подмножеств** в Node v22.17.1. Это проверка воспроизведения, не доказательство равномерности sort.

Отдельный [shuffle-bias.mjs](../../research/gdd-v2/shuffle-bias.mjs), 50 000 независимых seed на метод, выбирает 3 из фиксированно упорядоченных 20. Ожидаемая маргинальная частота каждого 15%:

| Алгоритм | Минимальная частота индекса | Максимальная | Первый элемент исходного пула |
|---|---:|---:|---:|
| Random comparator sort | 10,384% | 28,178% | 28,178% |
| Fisher–Yates | 14,718% | 15,382% | 14,810% |

[Данные распределения](../data/gdd-v2/shuffle-bias.json). Random comparator — не корректное перемешивание; размер и направление смещения зависят от порядка каталога/алгоритма sort/runtime. Этот тест маргинальных включений не исследует все 20! перестановок.

### Как меняются сохранённые выводы

Power-curve, balanced, те же 50 seed/враг:

| Колода | Обычные: ходы / HP — sort → FY | Элиты: ходы / HP — sort → FY | Финал: ходы / HP — sort → FY |
|---|---|---|---|
| Исходный 18 | 3,33 / 5,8 → то же | 6,00 / 10,1 → то же | 9,00 / 15,2 → то же |
| +8 рейтинговых карт | 3,11 / 5,7 → **3,23 / 5,3** | 5,29 / 10,9 → **5,41 / 10,7** | 8,34 / 14,4 → **8,36 / 14,7** |
| +8, удалить четыре заданные | 2,92 / 5,1 → **3,02 / 6,1** | 4,86 / 11,1 → **4,92 / 11,7** | 7,54 / 14,3 → **7,68 / 15,5** |
| +8 с bleed-приоритетом | 3,31 / 6,1 → **3,44 / 6,2** | 5,65 / 11,9 → **5,97 / 12,6** | 8,76 / 18,0 → **8,86 / 19,2** |

FY сохраняет качественный вывод: обычные рейтинговые добавления не дают крупного и одновременного улучшения темпа/безопасности. Но формулировка «кривой силы нет» слишком абсолютна: есть небольшие разные прибавки, удаление тоже может обменивать безопасность на скорость. Провал bleed-greedy не доказывает, что потенциал Кровотечения отсутствует.

rec11, D18, balanced, never-skip:

| Обычные враги | Лечение | sort → FY побед |
|---|---|---:|
| ×1 урон / ×1 HP | +6 одному, без checkpoint | 1,3% → **5,0%** |
| ×1 / ×1 | split10 +50% недостающего | 52,5% → **42,5%** |
| ×0,75 / ×0,8 | +6 одному, без checkpoint | 12,5% → **8,8%** |
| ×0,75 / ×0,8 | split10 +50% недостающего | 83,8% → **76,3%** |

По всем 40 строкам выбранного пути максимум наблюдённого сдвига побед — **12,5 п.п.** в 1/1 и **13,8 п.п.** в 0,75/0,8; максимум сдвига mean turns отдельного боя power-curve —0,32. [Сводка](../data/gdd-v2/shuffle-comparison.json), [старый replay](../data/gdd-v2/claude-recheck/sort/power-curve.json), [FY](../data/gdd-v2/claude-recheck/fisher-yates/power-curve.json).

Это **не чистая причинная оценка смещения win rate**: два shuffle потребляют разное число случайных чисел, а в long-run один поток также выбирает следующих врагов. При n=80 заметен и шум; не делать p-value по округлённым строкам. Для чистого нового опыта разделить потоки encounter/reward. Здесь сохранена остальная старая методика ради честного сравнения с историей.

Вывод о накоплении урона при механическом удлинении остаётся. Вывод «6 HP несовместимо ни с каким удлинением» не следует: модель не содержит улучшений, золота, предметов, человеческого драфта и адаптивного пути. Среди её heal-моделей также **нет точных A/B с +4 каждому**, поэтому она не выбирает B GDD.

Ещё ограничения первоначальных метрик:

- `cycles=drawn/deckSize` считает события добора, может включать повторы после перемешивания; это не точная доля уникальных копий, которые игрок увидел.
- `manaLeftPerTurn` добавляет остаток только после незавершённого хода, но делит на все ходы, включая победный. Для задачи «мана тратится почти вся» это требует оговорки; новый опыт считает ресурс каждого начатого хода.
- В long-run `nLossLate` среди дошедших — selection bias, а при ранней смерти «последние шесть боёв» не обязаны быть поздними боями сектора III.
- В synergy-odds уже правильный Fisher–Yates. Исправлять его как random sort не нужно. Комментарий «21-card» устарел: фактический массив содержит **20**. Мягкая подстройка заменяет слот и может создать повтор в предложении; модель не гарантирует уникальные реальные offers.
- Существующий greedy-рейтинг местами не ценит начальные bleed-карты. Даже добавление +10 тематического приоритета — конкретная стратегия выбора, не оптимальный драфт.

## Новый перекрёстный опыт стартов

[controlled-start.mjs](../../research/gdd-v2/controlled-start.mjs). Два ядра C14/L14 из GDD, для обоих один способ наращивания:

- N16 =ядро +Parry +Arcane Insight;
- N18 =N16 +Guard +Ice Ward;
- каждая колода с рукой 7 и 8; отдельно **буквальный текущий 18** также с двумя руками.

12 crossed-клеток +2 контроля, девять врагов v1.0, экономика B, полный HP, без предметов. Это размер как **конкретное разбавление заданными картами**, не абстрактный независимый N: изменение размера всегда меняет мультимножество. C18/L18 имеют по девять классовых карт и дополнительные защитные копии, не являются нынешним стартом 10/8.

Два диапазона `210000…210127` и `310000…310127`, balanced/defensive по128, planner по16 в каждом. Всего **68 544 отдельных боя**. Ограничения 40 ходов/24 plays; timeout фиксируется. Отдельно шесть стартов ×две стратегии ×три публичных route policy ×те же256 seed =**9 216 настоящих текущих семикомнатных походов**, с **52 403** боевыми эпизодами. Рейтинговые награды/предметы такие же, как в новом скрипте/метаданных, без skip/улучшений/золота; все сырые исходы походов сохранены.

Равное усреднение по шести каталоговым обычным врагам, balanced, оба диапазона:

| Старт | Ходы | HP Воин / Маг | Потери всего | Достигнуто 5 маны |
|---|---:|---:|---:|---:|
| Текущий 18/8 | 3,290 | 3,630 / 1,994 | 5,624 | 96,35% |
| C14/8 | 2,951 | 3,135 / 2,143 | 5,278 | 85,48% |
| L14/8 | 2,883 | 4,656 / 2,512 | 7,167 | 83,66% |
| C14/7 | 3,139 | 3,230 / 2,041 | 5,271 | 90,04% |
| L14/7 | 3,052 | 4,598 / 2,450 | 7,048 | 89,65% |
| C16/8 | 3,201 | 2,981 / 1,902 | 4,883 | 92,06% |

Состав при N14/H8 меняет ущерб примерно на1,89 HP, темп на0,068 хода. Смена только руки C14 с7 на8 сокращает ход на0,188, но средние потери почти не меняет; по героям эффект разнонаправлен. У defensive потери C14/8 2,075 против L14/8 2,782; у planner 6,568 против7,281. Нельзя вывести универсальную «силу размера» или оценивать одним ботом.

Фраза Claude «в обычном бою 5 маны почти не встречается» не подтверждается: в этом полном HP каталоге текущий balanced достигает5 в96,35% боёв. Это не утверждение о каждом уменьшенном враге первой карты, но достаточно, чтобы не строить дизайн на противоположной предпосылке. Отсутствие голодных рук поддерживает важность маны, **не бесполезность поиска карты** через добор.

Текущие походы, проценты побед по объединённым256 seed:

| Старт | balanced safe / mixed / risky | defensive safe / mixed / risky |
|---|---|---|
| Текущий18/8 | 89,1 / 77,3 / 26,2 | 99,2 / 97,3 / 62,9 |
| C14/8 | 84,4 / 79,3 / 35,5 | 99,6 / 99,2 / 86,7 |
| C14/7 | 84,0 / 72,7 / 27,7 | 98,8 / 97,3 / 71,9 |

C14/8 подтверждён как кандидат для опасного пути, но не как безусловный лучший старт; **safe balanced на новых seed хуже буквального18**, а C16 остаётся сильным компромиссом. Размер/состав/рука в протоколе независимы в пределах заданных вмешательств; маршруты mixed могут меняться из-за изменившегося HP, что является общим эффектом стратегии, не чистым эффектом боя.

## Что принято из исследований

Поддержаны: сначала развитие/управление, затем длина; слабая нынешняя цена риска; необходимость отдельного учёта двух HP; сохранение; независимые seed/публичная информация; польза специализированных возможностей вместо бесконечного добавления равных карт.

Ослаблены: универсальное превосходство14 или14/7; бесполезность добора; отсутствие любой кривой силы; невозможность любого длинного пути с6 HP; доказанная доступность сильного bleed-пакета по счётчику компонентов; готовность сложных золотых/девяти новых механик «почти без движка»; экономическая равноценность путей по формуле; прогноз минут людей по бот-ходам.

У Codex явно отделены синтетическое здоровье и topology-only, но эти числа тоже нельзя переносить на18/new rewards. Больший объём настоящих семикомнатных походов не делает гипотетическую21-комнатную игру проверенной. GDD принимает решение владельца о18 и сохраняет21 как эксперимент, а не выбирает автора по числу запусков.

## Воспроизведение

Из корня репозитория с его установленными зависимостями и указанными объектами Git:

```powershell
node research/gdd-v2/audit.mjs
node research/gdd-v2/shuffle-bias.mjs
node research/gdd-v2/controlled-start.mjs
npm test -- --reporter=dot
```

`audit.mjs` пишет только `docs/data/gdd-v2`; тела лабораторий читаются из Git и исполняются в памяти с перенаправленным `import.meta.url` вывода. Ни временных правок игрового каталога, ни merge веток. Результаты технического rerun не прибавляются дважды к опубликованному объёму.

Дополнительный объём проверки Claude: **9 000 отдельных боёв** power-curve (два метода), **12 800 линейных модельных походов** rec11 (два метода×два scaling×40×80). Это не 12 800 текущих кампаний и не новые GDD-походы. Результаты намеренно лежат рядом со своими ограничениями.

На неизменённой игре прошли **20 файлов /288 тестов**, включая эталон427 и public-информацию. Build не нужен как доказательство текста, игровых типов/Vue изменений здесь нет. Перед commit дополнительно проверяются локальные ссылки, охват23 улучшений, статусы/арифметика и отсутствие игровых изменений.
