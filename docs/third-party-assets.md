# Third-party assets and licenses

## Lucide Vue icons

- **Source:** [Lucide](https://lucide.dev/) / [Lucide Vue guide](https://lucide.dev/guide/vue)
- **Package:** `@lucide/vue` 1.59.0, imported locally and tree-shaken by Vite; no CDN.
- **License:** ISC. The package's full distributed notice, including the Feather-derived icon list and applicable MIT notice, is copied to [`../LICENSES/LUCIDE.txt`](../LICENSES/LUCIDE.txt).
- **Current Dungeon Map icons:** `Swords` (Обычный бой), `Crown` (Элитный бой), `Flame` (Привал), and `Skull` (Босс). These are from the library; their SVG paths are not authored or AI-generated by Spellwhim.
- **Card effect icons (Stage 2):** `Sword` (урон), `Shield` (броня), `CopyPlus` (добор), `Crosshair` (Уязвимость), `Ghost` (выбывает), `ChevronsUp` (активный бонус), `Lock` (не хватает маны). Mapped in `src/components/CardGlyph.vue`; library icons only, nothing drawn by hand.

Check the package metadata and license before upgrading or adding icons. Preserve required license notices when distributing the game. New UI icons should prefer this library for a consistent style; consult `AGENTS.md` for the project-wide icon rule.

## Fonts (local, bundled)

Bundled as woff2 files in `src/assets/fonts/` (Cyrillic and Latin subsets only), declared in `src/assets/fonts.css`, no CDN. Obtained from the Fontsource distribution of the Google Fonts releases (`@fontsource/el-messiri` 5.3.0, `@fontsource-variable/nunito` 5.3.0, `@fontsource-variable/rubik` 5.3.0) via `npm pack`; the npm packages are **not** project dependencies — only the font files and license texts were copied. All three are licensed under the SIL Open Font License 1.1 (embedding and redistribution with the game permitted; fonts must not be sold on their own; Reserved Font Names are not modified — no files were altered, only subsetted upstream).

Total payload ≈ 140 KB. `src/assets/fonts.test.ts` fails if a declared file is missing, an unused file is left in the folder, a family has no license text, or a font token points at an undeclared family. To add or replace a font: check Cyrillic coverage and the license first, add the license text to `LICENSES/`, extend this table and the test's license map.
