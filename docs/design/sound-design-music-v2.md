# Sound Design & Music Integration v2

## Область

Ветка основана на `origin/main` (`304fb04381175d9a64cbd206bd83669d76332e55`). Из discovery-ветки перенесены только перечисленные в задаче 23 одобренных файла. История discovery-ветки не вливалась и не cherry-pick-илась. Процедурный звуковой движок, battle rules, VFX-планы, единичный `impact` и корреляция `actionId` сохранены.

## Музыкальные темы

| ID | Назначение | Длительность | RMS / peak исходника | Trim |
|---|---|---:|---:|---:|
| `music-town-theme` | Главное меню и итоговый экран | 97,454 с | −15,64 / −0,07 dBFS | 0,88 |
| `music-cave-theme` | Карта, привал, кузница, событие, награда и просмотр колоды | 280 с | −14,10 / +0,68 dBFS | 0,78 |
| `music-battle-theme` | Обычные и элитные бои | 116,114 с | −15,28 / +0,15 dBFS | 0,86 |
| `music-bossfight` | Рак’Зор, обе фазы | 114,364 с | −10,98 / +0,43 dBFS | 0,52 |
| `music-victory-fanfare-short` | Победа | 11,842 с | −14,92 / +0,03 dBFS | 0,82 |

Измерены decoded PCM RMS и sample peak, не integrated LUFS и не субъективная громкость. Для четырёх длинных тем выбраны trims, приводящие средний исходный RMS примерно к −16,5 dBFS; Bossfight_ дополнительно приглушён на 5,7 dB из-за более высокого уровня. Это gain trim при воспроизведении: сами файлы не нормализовались и не перекодировались. Исходный peak после trim находится ниже примерно −1,1 dBFS даже при максимуме музыкального регулятора.

Решение темы вынесено в чистую `musicForContext()`:

- `menu` и экран итогов — Town Theme RPG.
- Все экранные состояния похода вне боя — Cave Theme. Изменения комнат и награды не перезапускают её.
- Любой бой, кроме боя с `old-mines-rhahk-zor`, — Battle Theme, в том числе элита.
- Бой с Рак’Зором по стабильному `encounterId` — Bossfight_. Фаза противника не участвует в выборе, поэтому фаза II не начинает трек заново.
- Фактическая победа выбирает одноразовую Victory Fanfare Short и после окончания возвращается к Cave Theme, а после финального боя — к Town Theme.
- Поражение оставляет процедурный сигнал поражения и затухает к тишине. Записанной темы поражения в отборе нет.

В `BattleBoard` процедурный victory-сигнал больше не запускается: фанфару выбирает только результат движка через App. Поэтому две фанфары не звучат параллельно.

## Переключение и зацикливание

Длинные композиции играет один постоянный `HTMLAudioElement` с `preload="none"`, подключённый к музыкальной GainNode-шине. Музыка декодируется и буферизуется браузером потоково; `GameAudio` не держит длинные треки целиком в `AudioBuffer`. Контекст и воспроизведение создаются только после разрешённого пользовательского ввода. Если Web Audio недоступен, тот же один media element работает с нативным volume.

При смене темы текущий поток плавно затихает примерно за 260 мс, останавливается и заменяется новым, который набирает уровень примерно за 520 мс. Второй музыкальный трек во время перехода не запускается. Повтор длинных тем вручную проходит через приглушение около конца файла и fade-in с начала; исходные границы и аудио не редактировались. У фанфары повтора нет: переход на другой экран во время короткой темы меняет только адрес возврата, а музыка экрана запускается после `ended`.

Не каждый источник заявляет seamless loop. Численные RMS/peak не доказывают музыкальную бесшовность, поэтому шов сглаживается коротким fade, а окончательное восприятие повтора проверяется владельцем на целевой системе.

## Записанные SFX

После trusted input короткие SFX загружаются и декодируются в фоне в пределах 18 небольших AudioBuffer-кандидатов. Событие запускает уже готовую запись или немедленный процедурный тембр, если запись ещё грузится/не найдена. Такая первая запасная нота не задерживает VFX/impact и не проигрывается позже задним числом.

| Игровое событие | Записанная подача |
|---|---|
| Начало боя: Вариан вынимает оружие | Kenney `rpg-draw-knife` |
| Лёгкий физический взмах | Kenney `rpg-knife-slice-a/b`, чередование |
| Тяжёлый взмах | Tinysized `fantasy-whoosh-a/b`, чередование |
| Обычное столкновение клинков / удар щитом | Tinysized `fantasy-sword-clash-a/b`; общий вариантный счётчик |
| Тяжёлое попадание | Tinysized `fantasy-hammer-hit-a/b` + тихий процедурный низкий ударный слой |
| Добор карты | Kenney `rpg-book-flip` |
| Розыгрыш карты | Tinysized `fantasy-book-page` |
| Получение карточной/артефактной награды | Kenney `rpg-coin-handling` / Tinysized `fantasy-coins`, чередование |
| Вход в обычную комнату/на привал | Kenney `rpg-metal-click` |
| Вход в кузницу/событие | Kenney `rpg-door-open` |
| Вход в сокровищницу | Kenney `rpg-metal-latch` / Tinysized `fantasy-lock-turn`, чередование |
| Редкий атмосферный деревянный скрип | Tinysized `fantasy-floor-creak` |

A/B-перебор ведётся отдельными счётчиками воспроизведения `createRecordingSelector()` и не читает seed или RNG боя. Сильные попадания, карты, VFX и механика по-прежнему решают, когда звук возможен; аудио не смотрит на закрытый размер подготовленной атаки.

Огонь, лёд, аркана, молния, кровотечение, блок/броня, interrupt, turn и часть тихих UI-событий остаются процедурными. Они не заменены записями, не имеющими подходящего назначения. UI сохраняет существующий тихий множитель; физические удары могут сосуществовать только с указанным сдержанным низким слоем тяжёлого попадания.

## Микс и настройки

Существующие bus effects и ambience сохранены; добавлена отдельная music bus. Все три шины проходят через прежний мягкий master compressor. Стартовые уровни: музыка 55%, эффекты 65%, окружение 30%. Трековые trims уменьшают разницу исходного RMS и оставляют запас на декодированные пики. Динамическое sidechain-приглушение не добавлялось: отдельный выигрыш не доказан, а прозрачность физических ударов обеспечивается их приоритетом и master headroom.

Панель `AudioSettings` теперь показывает mute, «Музыка», «Эффекты» и «Окружение». Ключ остаётся `spellwhim.audio.v1`; если у старого значения нет поля `music`, оно получает разумное значение по умолчанию 0,55, а старые mute/effects/ambience сохраняются. Изменение уровня шины применяется немедленно без замены или перезапуска композиции. Звуковые настройки остаются отдельно от run-save.

Mute обнуляет bus и останавливает короткие SFX/таймеры окружения; фоновой media stream остаётся на той же позиции без слышимого уровня, а unmute восстанавливает её. Скрытие страницы останавливает SFX и ставит media stream на паузу с сохранением позиции. При выходе из боя BattleBoard очищает ambient/audio scope; App выбирает музыку следующего экрана.

Если AudioContext отсутствует, музыка остаётся доступна через media element, а процедурные эффекты при необходимости кодируются в короткий временный WAV для нативного Audio element. Если запись отсутствует или не декодировалась, игра немедленно использует процедурный буфер. Все ветки ошибок декоративные: они не блокируют игровые действия. Источники ограничены 16, активные AudioNodes disconnect-ятся, URL fallback WAV удаляются при завершении.

## Файлы и лицензии

В новой ветке находится **ровно 23 аудиофайла**: пять тем и 18 эффектов, **18 039 467 байт / 17,20 MiB**. Звуки лежат в `src/audio/assets/{music,sfx}`. `docs/audio/candidates.json` содержит только реально включённые записи; для каждого ассета записаны автор, исходный filename, URL страницы, лицензия, размер, SHA-256, длительность, RMS и peak. Документ [ASSET_LICENSES.md](../audio/ASSET_LICENSES.md) даёт читаемую таблицу; оригинальные текстовые лицензии Kenney и README Tinysized лежат в `docs/audio/licenses/`.

Источники: [Kenney RPG Audio](https://kenney.nl/assets/rpg-audio), [Tinysized SFX](https://opengameart.org/content/fantasy-sound-effects-tinysized-sfx), [Town Theme RPG](https://opengameart.org/content/town-theme-rpg), [Battle Theme](https://opengameart.org/content/battle-theme-0), [Cave Theme](https://opengameart.org/content/cave-theme), [Bossfight_](https://opengameart.org/content/bossfight-1), [Victory Fanfare Short](https://opengameart.org/content/victory-fanfare-short). Страницы отдельных работ помечают эти ассеты CC0; для Cave Theme выбрана CC0 из двух лицензий страницы. ZIP и все отклонённые кандидаты исключены.

## Проверки и границы

Записанные технические длительности SFX — 0,26–2,04 с. Самые тихие source peaks — draw-knife (−24,29 dBFS) и metal-click (−6,93 dBFS); максимальный decoded peak выбранных коротких SFX — +1,91 dBFS у sword-clash B, и он подаётся в effects bus/compressor. Музыкальный уровень откалиброван по RMS и sample peak, не LUFS. Все 23 файла декодируются браузером; скрипт аудиокаталога проверяет пути, число, SHA-256, длительности, лицензии и отсутствие отклонённых имён.

Результаты выполнения:

- `npm test` — 48 файлов, 985 тестов прошли.
- `npx vue-tsc -b --force` — без ошибок.
- `npm run build` — production build прошёл; Vite сообщает обычное предупреждение о чанке JS больше 500 kB.
- `npm run audio:catalog:check` — 5 тем и 18 SFX, хеши, длительности, лицензии и пути прошли проверку; общий объём 18 039 467 байт.
- `scripts/app-smoke.mjs ... --sizes 2560x1440 --audio` — живая игра, переходы меню/карта/бой/победа, один поток музыки, сохранённая громкость, mute/unmute и восстановление похода.
- `scripts/vfx-check.mjs --size 2560x1440 --fx fireball,shield-bash,enemy-block,boss-all --rapid` — сцены и серия из 10 эффектов завершились без оставшихся объектов или работающего ticker; browser smoke также дошёл до награды без ошибок консоли.

Технические проверки не заменяют субъективное прослушивание владельцем через целевые колонки/наушники: особенно стоит оценить кульминационный бой, звучание физических вариантов A/B, громкость монет, повтор каждой фоновой темы и тишину на переходах.

## Прослушивание в игре и библиотеке

Для живой игры запусти `npm run dev`, открой показанный Vite URL и нажми любую кнопку стартового меню — браузер разрешает музыку только после этого действия. Создай поход: Town Theme сменится на Cave Theme; при входе в бой начнётся Battle Theme. Ползунок «Музыка» в кнопке громкости применяется во время текущего трека; там же доступны эффекты, окружение и mute.

Чтобы отдельно сравнить те же утверждённые записи, открой `/audio-preview.html`. Здесь 5 композиций и 18 SFX, один preview-плеер, seek, громкость, повтор для музыки и локальные оценки A/B.

```sh
npm run audio:catalog:check
npm run dev
node scripts/app-smoke.mjs balance-reports/sound-design-v2 --base http://127.0.0.1:5177 --sizes 2560x1440 --audio
node scripts/vfx-check.mjs --base http://127.0.0.1:5177 --size 2560x1440 --fx fireball,shield-bash,enemy-block,boss-all --rapid
```
