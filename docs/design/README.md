# Дизайн Spellwhim

Основной документ целевой игры — [Game Design Document v2.0](spellwhim-gdd-v2.md). **Действующие правила игры — B2 Long (решение X04):** [что играется и как устроен переход](default-b2-long-v1.md); где GDD или старые отчёты говорят иначе (рука 8, мана 3→4→5, броня до удара, короткий сектор), это история или контрольная модель. Сверка текстов, подсказок и документов с кодом — [аудит v1](../reviews/ux-consistency-legacy-audit-v1.md). Он различает согласованные направления, прототипы, эксперименты и фактически реализованные системы. Текущие боевые правила до реализации соответствующих этапов определяет код; старый исследовательский документ не переопределяет новую явно принятую концепцию.

- [Method Audit](../research/gdd-v2-method-audit.md) — проверка обоих исследований и новые данные.

- [B2 Long — основная игра (X04, 24.10.2026)](default-b2-long-v1.md) — принятие конфигурации, упрощённое меню, сохранения и dev-доступ к прежним режимам.

Другие файлы в этом каталоге сохраняются как материалы прежних исследований. При расхождениях сначала проверять статус решения GDD и дату/версию реализации, не смешивать исторические числа наград/предметов с текущим кодом.
