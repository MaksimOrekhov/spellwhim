# Дизайн Spellwhim

Основной документ целевой игры — [Game Design Document v2.0](spellwhim-gdd-v2.md). Он различает согласованные направления, прототипы, эксперименты и фактически реализованные системы. Текущие боевые правила до реализации соответствующих этапов определяет код; старый исследовательский документ не переопределяет новую явно принятую концепцию.

- [Decision Log](spellwhim-gdd-v2-decisions.md) — что выбрано из исследований и почему.
- [Experimental Plan](spellwhim-gdd-v2-experiments.md) — контролируемые проверки и пределы выводов.
- [Implementation Roadmap](spellwhim-gdd-v2-roadmap.md) — самостоятельные этапы с gates.
- [Card Progression Foundation v1](tasks/card-progression-foundation-v1.md) — черновик первой задачи, ещё не реализован.
- [Method Audit](../research/gdd-v2-method-audit.md) — проверка обоих исследований и новые данные.
- [B2 Long — основная игра (X04, 24.10.2026)](default-b2-long-v1.md) — принятие конфигурации, упрощённое меню, сохранения и dev-доступ к прежним режимам.
- [Честный ход B1/B2 — тактическое давление и «Мороз и сталь»](honest-turn-b-experiment-v1.md) — два играбельных варианта поверх A, исследование стартовой колоды (броня 10/8/6), отчёт и сценарий человеческого плейтеста (EXPERIMENT X02, 22.10.2026); не заменяют правила GDD.
- [Длинный сектор I — 10 посещений](sector-one-long-v1.md) — экспериментальный маршрут для B1/B2: структура, три новых врага, лаборатория короткий/длинный, известные ограничения и сценарий плейтеста (EXPERIMENT X03, 24.10.2026).
- [Честный ход A — экспериментальный режим](honest-turn-a-experiment-v1.md) — играбельный прототип для сравнения с текущей игрой (EXPERIMENT X01, 21.10.2026); не заменяет правила GDD.

Другие файлы в этом каталоге сохраняются как материалы прежних исследований. При расхождениях сначала проверять статус решения GDD и дату/версию реализации, не смешивать исторические числа наград/предметов с текущим кодом.
