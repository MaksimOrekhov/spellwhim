# Старые штольни — Visual Polish v1

20.10.2026. База — `main` (`96d19fb`, Sector I balance v1.1 уже объединён). Ветка — `claude/deadmines-sector-one-visual-polish-v1`. Задача — только оформление и UX первого сектора; правила, баланс, генератор, комнаты, сохранения и колода не менялись.

## Что улучшено

| Экран | Что сделано |

Узлы — «доски» с круглой медалью-иконкой; цвет по типу: бой — сталь, элита — красная доска, событие — голубой, кузница — оранжевый, сокровищница — золотой, привал — зелёный, босс — крупный фиолетовый с золотой рамкой. Старые экраны «Поход завершён»/«Отряд пал» сохранены, оформлены теми же токенами. |

## UX

- При открытом выборе описания действий и сюжетная карточка сворачиваются (`is-compact`): раньше на 1280×720 список копий и артефакты уезжали за край и обрезались; теперь список карт виден целиком с прокруткой только внутри комнаты.
- Контент пустой комнаты вертикально не прижимается к низу, цели нажатия не меньше прежних (карточки ≥ 54 px).
- `prefers-reduced-motion` выключает искры. Пульсация доступных узлов не блокирует взаимодействие.
- Логика `DungeonRoom.vue` (`select`/`confirm`, `roomId`, `replaceInstanceId`, `canConfirm`, отмена) осталась прежней — менялись только разметка, иконки и CSS.

Подключены через существующий реестр `src/ui/enemyArt.ts` по стабильным ID `old-mines-johnson` / `old-mines-rhahk-zor`; `EnemyFrame.vue` больше не содержит особого случая для эмблем. Новых зависимостей нет; новые Lucide-иконки (`Flag`, `Check`, `Trophy`, `Bomb`, `Handshake`, `Hammer`, `Dices`, `Gift` и др.) взяты из уже установленного `@lucide/vue`.

**Временное:** оба портрета — векторная «заглушка высокого качества», а не Krea-живопись: по фактуре они чище и плоскостнее Krea-портретов Вариана и Джайны. Желательно позже заменить на растровые Krea-портреты в том же стиле (формат — квадрат ~768, лицо в центре; файлы подменяются в `enemyArt.ts` без других правок). Остальные враги сектора по-прежнему используют повторно Krea-портреты.

## Что осталось / ограничения

- Не добавлены уникальные иллюстрации комнат (кузница, тайник, события) — сцены строятся тематическим светом, иконками и силуэтом. Полноценные фоновые арты — отдельная задача.
- Карта: вертикальные переходы между соседними рядами частично закрыты самими узлами (зазор ≈ 24 px), поэтому рельсы лучше всего видны на диагоналях.
- Мобильная вёрстка карты не пересматривалась (прежняя горизонтальная прокрутка).
- `UpgradePicker` общий с привалом и визуально не менялся.
- На 1920×1080 экраны комнат выглядят просторнее (больше пустоты вокруг центральной колонки), но читаемость не страдает.

## Тесты и сборка

- `npm test` — 28 файлов, **672 теста пройдено**. Единственная правка теста: `cardPoolExpansion.test.ts` фиксировал число зарегистрированных портретов (13) — теперь 15 из-за двух новых.
- `npm run build` — успешно (`vue-tsc -b` + `vite build`; прежнее предупреждение о размере чанка).
