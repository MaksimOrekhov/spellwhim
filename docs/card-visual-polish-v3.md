# Card Visual Polish v3 — карта как игровой предмет

Ветка `feature/card-visual-polish-v3`. Правила, числа карт, стоимость, баланс B2 Long и сохранения не менялись: все значения по-прежнему приходят из `cardFace` / `previewCard`.

## Что не устраивало

Тёмные «пилюли»-чипы на плоской плашке пергамента, отдельная строка «ВОИН · АТАКА», одинаковые полоски на всех картах, при активной связке (Ледяная стрела: +2 броня, +3 Уязвим, метка) нижняя часть переполнялась и обрезалась, а плитка руки была просто обрезком арта с двумя пилюлями.

## Сравнённые направления

| | Идея | Итог |
|---|---|---|
| A. «Витрина» | арт в окне с гравированным кантом, плашка названия на стыке арта и текста, числа — гемы, украшения по углам | **выбрано**: читается в руке, помещаются правила, арт крупный |
| B. Арт на всю карту | текст поверх тёмного градиента | отклонено: правила и теги не читаются на живописных артах, класс теряется |
| C. Только перекраска v0.2 | новые цвета, тени и радиусы | отклонено: не меняет восприятие |

## Что сделано

- `src/assets/cards.css` — общая карточная система (`cf-*`): рама воина (бронза, сталь, заклёпки) и мага (сапфир, аметист, арка, кристалл-корона), окно арта с кантом, пергамент с водяным знаком класса, плашка названия, гемы-числа со значками смысла, печать класса, кристалл маны, звезда улучшения, состояния, «стопка» дубликатов. Материалы — новые токены `--mat-gem-*`, `--mat-card-paper`, `--glow-upgrade` в `tokens.css`; цвета классов только из `classThemes.ts`.
- `SpellCard.vue` — раскладка полной карты; строка «класс · тип» убрана с лица (класс — рама, печать и водяной знак; текст остаётся в `CardNotes`, aria-label и подсказках). При тесноте активные бонусы — «пилюли».
- `CompactCard.vue` — та же система в уменьшенном виде (внутри 1em = 1/12 ширины, как у полной карты).
- `CardGallery.vue`, `DeckViewer.vue` — «стопка» вместо числа в углу, значок «Выбрана»; `CardReward.vue` — карты крупнее (предел 28px); `CardOperationDialog.vue` — крупнее сравнение; `CardNotes.vue` — заголовок в цвете класса; `CardGlyph.vue` — глиф улучшения.
- Dev-лаборатория `CardLab.vue` (`card-preview.html?view=sheet|states|deck|ops`) и `scripts/card-shots.mjs` для воспроизводимых снимков.
- Тесты `src/ui/cardVisual.test.ts`: числа, цена, класс, улучшение, состояния и паритет полной карты и плитки для всех карт каталога.
