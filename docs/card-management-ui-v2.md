# Card Management UI v2

Ветка `feature/card-management-ui-v2` (от `experiment/honest-turn-b`). Механика, баланс, колоды, генерация карты и награды не менялись.

## Что изменилось
- `CardOperationDialog.vue` заменил `UpgradePicker.vue` и встроенные списки удаления/замены в `DungeonRoom.vue`. Один диалог для привала, бесплатной и платной (событие) кузницы, удаления и замены.
- `CardGallery.vue`: колода показана настоящими `SpellCard`; одинаковые копии (то же определение и то же улучшение) — одна плитка с «×N», улучшенные — отдельные плитки. Под картой: название, класс и мана, главные числа. Фильтр по классу, стрелки/Home/End, Enter/Space выбирают. Недоступные карты видны, но затемнены с причиной («Уже улучшена»).
- Улучшение: слева направо «Сейчас → Станет ↑», строки «Урон врагу 5 → 7», подсвеченные новые слова описания.
- Удаление: большая карта + свиток правил, «Карт в колоде: 20 → 19», предупреждение о необратимости, отдельное предупреждение о потере улучшения. Выбор ничего не удаляет — только «Удалить навсегда».
- Замена: «Исчезнет» → три настоящие карты-предложения, «Появится» у выбранной; сообщение, что улучшение не переносится.
- Операция всегда над одним конкретным `instanceId` (первая допустимая копия плитки). Черновик (`instanceId`, `cardId`) сохраняется как раньше через `selectRoom`; при перезагрузке диалог открывается с тем же выбором.

## Проверка
`npm test`, `npm run build`, браузерная проверка кузницы, платной кузницы, привала, удаления/замены обычных и улучшенных копий при 1280×720, 1920×1080 и 800×700. Скриншоты — `docs/screenshots/card-management-v2/`.
