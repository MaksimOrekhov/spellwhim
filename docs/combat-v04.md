# Enemy AI & Intent v0.4

## Модель

Каждый encounter хранит декларативный цикл действий для первой и, если нужно, второй фазы. `BattleState.enemy.nextAction` одновременно служит анонсом для UI и командой для правил; прогноз не выбирает цель и не меняет состояние. Цикл детерминирован, а начальное перемешивание колоды по-прежнему использует seed.

Подготовка — отдельное действие без урона. После него точная атака с фиксированной целью становится следующим намерением. После удара Стража идёт безопасная Передышка с 2 бронёй, затем цикл подготовки начинается снова. Игрок может прервать последовательность победой, и никакой отложенный эффект после этого не применяется.

| Противник | Паттерн |
| --- | --- |
| Корневой дозорный | 4 урона Лире → 5 брони себе → 5 урона Бранну |
| Страж старой рощи | подготовка удара на 10 по Бранну → удар → передышка 2 → подготовка удара на 9 по Лире → удар → передышка 2 |
| Сумеречное сердце, фаза I | 6 по Лире → 3 обоим (основная цель Бранн) → 5 брони себе |
| Сумеречное сердце, фаза II | 7 по Бранну → 4 обоим (основная цель Лира) → 6 брони себе |

## Урон и защита

Входящий урон сначала снимает броню противника, затем здоровье. Карточный прогноз показывает этот разбор; связки активируются и расходуются по прежним правилам независимо от того, сколько урона прошло в здоровье. Броня противника ограничена 8 очками, чтобы повторяющиеся защитные циклы оставались контрируемыми.

Массовый удар вычисляет оба результата до применения. «Защитная стойка» защищает объявленную основную цель, «Каменный бастион» дополнительно защищает напарника. Броня каждого героя уменьшается только при попадании по нему.

## Фазы босса

Фаза II включается при здоровье не выше половины. Уже объявленный `nextAction` и метка фазы самого намерения сохраняются до исполнения, даже если порог пересечён карточным ударом в середине хода игрока. После исполнения продолжение цикла берётся из паттерна второй фазы, начиная с его первого действия. Портрет получает текущую фазовую плашку и короткий визуальный акцент.

## Намерения и анимации

`forecastEnemyAction` возвращает тип действия, фазу, расчётные попадания, будущие попадания после подготовки и объём брони. `endTurn` использует тот же прогноз для разрешения, в том числе для одновременного AoE. `EnemyIntent` показывает фактические потери каждому герою, броню и подготовленную цель. PixiJS визуализирует защиту, накопление энергии, тяжёлый удар и попадания по обоим портретам. ID анимационного действия сохраняет защиту от повторного применения.

## Баланс и сценарии

Точные атаки Стража — 10/9, поскольку они заранее объявлены и между ними есть атакующее окно и передышка. Массовая атака босса наносит 3/4 каждому; усиление фазы заметно и затрагивает обоих героев. Армор врага ограничен 8.

`runStrategyComparison(seed)` прогоняет агрессивную, защитную и смешанную стратегии против трёх противников с одними правилами боя и карт. В выводе `npm run scenarios -- 42` видны ходы, урон, остаток здоровья и последовательность сыгранных карт. Результаты воспроизводимы при одинаковом seed и позволяют сравнивать не только победу, но и цену в здоровье/ходах.
