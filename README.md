# Spellwhim: Сумеречная чаща

Одиночный карточный PvE roguelike-прототип на Vue 3, TypeScript, PixiJS 8 и Tauri 2. Бранн и Лира используют общую колоду и общую ману: 3 кристалла в первом ходу, 4 во втором, затем максимум 5. Они проходят три боя, сохраняют здоровье между ними и получают карты-награды. Vue рисует интерфейс, PixiJS — боевые эффекты; правила работают отдельно от графики.

## Запуск

Требуются Node.js 20.19+ или 22.12+ и npm. Для настольной сборки нужны Rust stable и [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).

```bash
npm install
npm run dev
# Настольный режим:
npm run tauri dev
```

Адрес Vite обычно `http://localhost:5173`. Нажмите карту, чтобы разыграть её; завершение хода запускает показанную атаку врага. Смерть любого героя означает поражение.

## Боевой интерфейс v0.3

Общий ход отряда явно отделён от розыгрыша карты и атаки противника. Намерение показывает цель, броню и ожидаемую потерю здоровья. Активные связки отмечены возле персонажей и усиливают предпросмотр подходящих карт. Карта разыгрывается кликом или клавишами 1–9 и 0; Enter завершает ход, кнопка «?» открывает справку.

[Обзор переработки, проверки, скриншоты и ограничения](docs/combat-ui-v03.md).

## Колода и связки v0.2

Стартовая колода содержит 18 карт — по две копии девяти способностей Воина и Мага. В начале боя игрок получает 8 карт; максимум руки — 10. Несыгранные карты сохраняются между ходами; в начале хода 2–4 добираются 2 карты, начиная с хода 5 — 3. Мана полностью восстанавливается в начале хода, а неизрасходованный остаток не переносится. Прогрессия начинается заново в каждом бою. Если рука заполнена, добор блокируется, карты остаются в колоде. Все эффекты добора соблюдают тот же лимит. Когда колода пуста, сброс перемешивается. Сыгранная платная карта после повторного добора может снова попасть в руку; Быстрый выпад выбывает до конца боя.

- **Маг → воин:** Огненный шар накладывает метку. Следующий удар Бранна расходует её: +3 урона и добор.
- **Воин → маг:** Стойка и Бастион создают защитный резонанс. Следующее атакующее заклинание Лиры расходует его: +2 урона.
- Оба состояния не суммируются и истекают в конце текущего хода игрока. Подходящие карты подсвечены и показывают фактический бонус.
- Защита прикрывает героя под прицелом. Бастион даёт броню также напарнику; она сохраняется до атаки по владельцу. Между боями щиты и состояния очищаются.

[Правила, обнаруженные проблемы, роли карт, сценарии баланса и следующие задачи](docs/combat-v02.md). Новая система руки и стартовых карт описана в [Combat Depth v0.6](docs/combat-depth-v06.md).

Незафиксированные идеи следующих этапов и долгосрочное направление Party System (свободный выбор двух героев) — в [дизайн-бэклоге](docs/game-design-backlog.md). Это планы, а не реализованные механики.

## Проверки и сценарии без UI

```bash
npm test
npm run build
npm run scenarios -- 42
npm run balance            # Balance Lab: aggressive, defensive, balanced и planner
npm run balance -- --strategy baseline   # только три классические стратегии
npm run balance:smoke
npm run tauri build
```

Balance Lab играет настоящие походы без интерфейса. У него четыре стратегии: три классические эвристики (`aggressive`, `defensive`, `balanced`, остаются контрольными) и четвёртая, `planner`. Планировщик перебирает последовательности карт всего хода через настоящий движок и видит только то, что известно игроку: порядок колоды, `seed`, состояние генератора и идентификаторы карт на его решения не влияют (подробности, проверки и сравнение — в [docs/balance-planner.md](docs/balance-planner.md)).

Сценарии принимают seed и не требуют браузера. Детерминированный RNG, зоны колоды и ожидающий розыгрыш находятся в `BattleState`. Для собственных сценариев используйте `createBattle` с `{ seed, deck, openingHandSize }`, `playCard(state, instanceId)` и `endTurn(state)`. Последняя команда сборки требует системных зависимостей Tauri.

## Экономика боя v0.7

В игре по умолчанию включена **модель B**: 3→4→5 маны (максимум 5), враги v0.7 и поздний добор. Она работает в `npm run dev`, production и Tauri без параметров URL. Модель A сохраняет старую экономику v0.6 для контроля в Balance Lab; U остаётся исследовательской.

```bash
npm run dev
# dev-сравнения: http://localhost:5173/?economy=A или ?economy=U (без параметра — стандартная B)
npm run economy -- --configs A,B,U --runs 300 --seed 20000   # Balance Lab: сравнение моделей
```

В бою HUD показывает текущую ману, рост максимума на следующем ходу и достижение лимита 5. Правила и результаты симуляций — в [отчёте Combat Economy v0.7](docs/combat-economy-v07.md).

## Архитектура

- `src/game/types.ts` — шаблоны и экземпляры карт, декларативные эффекты, связки, враги и состояние.
- `src/game/battle.ts` — проверка, оплата, план и однократное разрешение действия; расчёт предпросмотра и конец хода.
- `src/game/deck.ts` — seeded RNG, перемешивание, добор и сброс.
- `src/game/scenarios.ts`, `scripts/run-combat-scenarios.mjs` — сценарии без графического интерфейса.
- `src/game/balance.ts`, `src/game/balancePlanner.ts`, `scripts/run-balance.mjs` — headless Balance Lab и стратегия `planner`.
- `research/mana/` — изолированный исследовательский симулятор экономики маны; в сборку игры не входит и не используется её кодом.
- `src/composables/useBattle.ts` — реактивный адаптер правил и колода похода.
- `src/composables/useBattleAnimation.ts` — Pixi/fallback-события по ID, тайминги и отмена.
- `src/components/` — карта похода, сцена, рука, портреты, награды и PixiJS слой.
- `src/assets/art/` — девять оригинальных AI-иллюстраций и две классовые SVG-эмблемы из Game-icons.net.
- `src-tauri/` — оболочка Tauri 2. Проектные инструкции — в `AGENTS.md`.

## Ограничения

Один маршрут, два героя, девять стартовых способностей и расширяемый набор наград; Balance Lab моделирует три простые эвристики и планировщик хода, а не опытного игрока. Нет звука, сохранений и редактора колоды. Иллюстрации карт в `src/assets/art/` относятся к прежнему прототипу; новые способности используют временные SVG-заглушки и ждут отдельного арта. Классовые эмблемы — внешние SVG Game-icons.net по CC BY 3.0; авторство указано ниже. Сцена и эффекты процедурные, шрифты используют локальные fallback, сеть при игре не требуется.
