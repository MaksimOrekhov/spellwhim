# Spellwhim: Сумеречная чаща

Небольшой PvE-прототип карточного боя на Vue 3, TypeScript, PixiJS 8 и Tauri 2. Интерфейс и карты собраны Vue-компонентами, чистые правила боя находятся в `src/game`, а PixiJS рисует лёгкие процедурные вспышки и частицы поверх сцены. Портреты Бранна, Лиры и лесного стража, а также арты трёх карт — оригинальные AI-сгенерированные иллюстрации в `src/assets/art/`. Они подключены как заменяемые ресурсы; остальная сцена и боевые эффекты созданы CSS и PixiJS. Извлечённых из игр изображений, звуков и шрифтов нет.

## Требования

- Node.js 20.19+ или 22.12+ и npm
- Для настольной сборки: Rust stable и системные зависимости Tauri 2. См. официальную инструкцию Tauri по платформе: https://v2.tauri.app/start/prerequisites/

## Установка и запуск

```bash
npm install
npm run dev
```

Откройте адрес Vite, обычно `http://localhost:5173`. Для приложения Tauri:

```bash
npm run tauri dev
```

## Проверка и сборка

```bash
npm test
npm run build
npm run tauri build
```

`npm run build` собирает и проверяет TypeScript/Vue, `npm test` запускает тесты правил боя. `npm run tauri build` создаёт платформенный пакет Tauri при установленных системных зависимостях.

## Управление

Нажмите карту или перетащите её вверх, чтобы разыграть. Карты с недостаточной стоимостью маны приглушены. «Завершить ход» позволяет стражу атаковать показанного героя; броня поглощает урон. Победа, поражение и перезапуск управляются игровыми правилами.

## Архитектура

- `src/game/types.ts` — типы героев, карт и состояния.
- `src/game/battle.ts` — независимые от рендеринга правила и инициализация боя.
- `src/composables/useBattle.ts` — реактивный адаптер состояния и игровые действия.
- `src/components/` — сцена, переиспользуемый портрет героя, карта и PixiJS слой эффектов.
- `src/assets/art/` — портреты героев и противника; их можно заменить отдельными файлами без изменения боевой логики.
- `src/assets/main.css` — масштабируемый фэнтезийный арт сцены и карточный интерфейс.
- `src-tauri/` — минимальная оболочка Tauri 2.

Все шесть иллюстраций сгенерированы встроенным ImageGen специально для прототипа; внешние игровые ассеты не используются. Шрифты используют локальные системные `Georgia`/serif и Manrope fallback; сеть при запуске не нужна.

## Известные ограничения

- Сцена использует процедурные CSS-иллюстрации, а не финальные персонажные арты.
- Игровое поле рассчитано на один бой; колоды, постоянные эффекты и звук не реализованы.
- PixiJS отвечает за частицы и вспышки, а композиция поля остаётся HTML/CSS для доступной адаптивной верстки.
- Цель — лёгкий рендер на типичном компьютере; конкретный FPS зависит от оборудования и встроенного WebView.
