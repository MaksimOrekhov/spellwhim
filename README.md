# Spellwhim: Сумеречная чаща

Одиночная карточная PvE roguelike-игра на Vue 3, TypeScript, PixiJS 8 и Tauri 2. Вариан Ринн и Джайна Праудмур используют общую колоду и ману 3→4→5 (максимум 5), выбирают путь по карте штреков, переносят здоровье между встречами и пополняют колоду. Vue рисует интерфейс, PixiJS — боевые эффекты; правила работают отдельно от графики.

## Запуск

Требуются Node.js 20.19+ или 22.12+ и npm. Для настольной сборки нужны Rust stable и [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).

```bash
npm install
npm run dev
# Настольный режим:
npm run tauri dev
```

Адрес Vite обычно `http://localhost:5173`. Нажмите карту, чтобы разыграть её; завершение хода запускает показанную атаку врага. Смерть любого героя означает поражение.

## Боевой интерфейс v0.3

Общий ход отряда явно отделён от розыгрыша карты и атаки противника. Намерение показывает цель, броню и ожидаемую потерю здоровья. Состояние «Уязвим» отображается у портрета противника, а готовый бонус — в предпросмотре подходящей карты. Карта разыгрывается кликом или клавишами 1–9 и 0; Enter завершает ход, кнопка «?» открывает справку.

[Обзор переработки, проверки, скриншоты и ограничения](docs/combat-ui-v03.md).

## Боевые синергии v0.8

Эффект **«Уязвимость»** принадлежит текущему противнику. Следующая наносящая урон карта любого класса получает +3 урона и снимает эффект. Состояние сохраняется между ходами, не накапливается и очищается после боя. Ледяная стрела и Удар щитом могут накладывать Уязвимость; любая карта с фактическим эффектом урона может её расходовать.

Ледяная стрела и Грозовой разряд наносят дополнительно 2 урона, если у Джайны есть броня. Этот бонус не расходует броню и суммируется с Уязвимостью. Текущие карты, точные правила, симуляции и ручные проверки описаны в [отчёте Hero Identity & Vulnerability Combat v0.8](docs/hero-identity-breach-v08.md).

## Карта подземелья v0.1

Поход начинается с детерминированной карты из шести слоёв и финальной встречи. Каждый слой содержит три связанных штрека. Можно идти через обычные бои ради карты-награды, выбрать элиту с более ценным выбором из пяти карт или свернуть на привал и восстановить до 6 HP одному герою. Награда за обычный бой — выбор из трёх карт. Пути без тупиков; стартовые узлы дают выбор, а всякий маршрут включает не менее четырёх боёв вместе с финалом.

Карта, бой и награда каждого узла получают отдельные детерминированные seed, поэтому порядок выбора маршрута не меняет уже заданные встречи и предложения карт. Seed похода показан на карте; кнопка «Новый поход» создаёт новую раскладку. Подробности генерации, состояния похода, проверок и ограничений — в [Dungeon Map Foundation v0.1](docs/dungeon-map-foundation-v01.md).

Категории узлов обозначаются локальными иконками Lucide; источник и полный текст лицензии зафиксированы в [реестре сторонних ассетов](docs/third-party-assets.md).

Стартовая колода содержит 18 карт — по две копии девяти способностей Воина и Мага. В начале боя игрок получает 8 карт; максимум руки — 10. Несыгранные карты сохраняются между ходами; добор — 2 карты в ходы 2–4 и 3 карты с хода 5. Мана полностью восстанавливается в начале хода; прогрессия начинается заново в каждом бою. Лимит руки сохраняет заблокированные карты в колоде, а пустая колода пополняется перемешанным сбросом. Быстрый выпад выбывает до конца боя.

## Проверки и сценарии без UI

```bash
npm test
npm run build
npm run scenarios -- 42
npm run balance            # Balance Lab: aggressive, defensive, balanced и planner
npm run balance -- --strategy baseline   # только три классические стратегии
npm run balance:smoke
npm run tauri build
```

Balance Lab играет настоящие походы без интерфейса. У него четыре стратегии: три классические эвристики (`aggressive`, `defensive`, `balanced`, остаются контрольными) и четвёртая, `planner`. Планировщик перебирает последовательности карт всего хода через настоящий движок и видит только то, что известно игроку: порядок колоды, `seed`, состояние генератора и идентификаторы карт на его решения не влияют (подробности, проверки и сравнение — в [docs/balance-planner.md](docs/balance-planner.md)).

Сценарии принимают seed и не требуют браузера. Детерминированный RNG, зоны колоды и ожидающий розыгрыш находятся в `BattleState`. Для собственных сценариев используйте `createBattle` с `{ seed, deck, openingHandSize }`, `playCard(state, instanceId)` и `endTurn(state)`. Последняя команда сборки требует системных зависимостей Tauri.

## Экономика боя v0.7

В игре по умолчанию включена **модель B**: 3→4→5 маны (максимум 5), враги v0.7 и поздний добор. Она работает в `npm run dev`, production и Tauri без параметров URL. Модель A сохраняет старую экономику v0.6 для контроля в Balance Lab; U остаётся исследовательской.

```bash
npm run dev
# dev-сравнения: http://localhost:5173/?economy=A или ?economy=U (без параметра — стандартная B)
npm run economy -- --configs A,B,U --runs 300 --seed 20000   # Balance Lab: сравнение моделей
```

В бою HUD показывает текущую ману, рост максимума на следующем ходу и достижение лимита 5. Правила и результаты симуляций — в [отчёте Combat Economy v0.7](docs/combat-economy-v07.md).

## Исследования и планы

Исследовательские данные U сохранены, но эта модель не входит в основной геймплей.

- [Исследование прогрессии маны](docs/mana-progression-research.md) — сохранённый снимок исследования; его модель U не является стандартной. Изолированный симулятор и воспроизведение результатов — в [research/mana/README.md](research/mana/README.md).
- [Дизайн-бэклог](docs/game-design-backlog.md) — идеи будущих итераций, в том числе направление Party System. Оно пока только описано и не реализуется.

## Архитектура

- `src/game/types.ts` — шаблоны и экземпляры карт, декларативные эффекты, враги и состояние.
- `src/game/battle.ts` — проверка, оплата, план и однократное разрешение действия; расчёт предпросмотра и конец хода.
- `src/game/deck.ts` — seeded RNG, перемешивание, добор и сброс.
- `src/game/scenarios.ts`, `scripts/run-combat-scenarios.mjs` — сценарии без графического интерфейса.
- `src/game/balance.ts`, `src/game/balancePlanner.ts`, `scripts/run-balance.mjs` — headless Balance Lab и стратегия `planner`.
- `research/mana/` — изолированный исследовательский симулятор экономики маны; в сборку игры не входит и не используется её кодом.
- `src/composables/useBattle.ts` — реактивный адаптер правил и колода похода.
- `src/composables/useBattleAnimation.ts` — Pixi/fallback-события по ID, тайминги и отмена.
- `src/components/` — карта похода, сцена, рука, портреты, награды и PixiJS слой.
- `src/assets/art/` — игровые портреты Вариана и Джайны, иллюстрации карт и классовые SVG-эмблемы из Game-icons.net.
- `src-tauri/` — оболочка Tauri 2. Проектные инструкции — в `AGENTS.md`.

## Ограничения

Один маршрут, два героя, девять стартовых способностей и расширяемый набор наград; Balance Lab моделирует три простые эвристики и планировщик хода, а не опытного игрока. Нет звука, сохранений и редактора колоды. Портреты Вариана и Джайны — временные пользовательские игровые ресурсы; см. `ASSET_MANIFEST.md`. Некоторые иллюстрации новых способностей пока используют SVG-заглушки. Классовые эмблемы — внешние SVG Game-icons.net по CC BY 3.0; авторство указано ниже. Сцена и эффекты процедурные, шрифты используют локальные fallback, сеть при игре не требуется.
