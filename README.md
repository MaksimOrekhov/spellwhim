# Spellwhim: Мёртвые копи

Личная фанатская карточная PvE roguelike-игра во вселенной Warcraft на Vue 3, TypeScript, PixiJS 8 и Tauri 2. Вариан Ринн и Джайна Праудмур спускаются в Старые штольни Мёртвых копей, играют общей колодой в общий ход, выбирают путь по карте штреков и доходят до Рак'Зора. Vue рисует интерфейс и карты, PixiJS — боевые эффекты; правила работают отдельно от графики.

Основная игра — «Честный ход B2» на длинном секторе I (решение X04 в [Decision Log](docs/design/spellwhim-gdd-v2-decisions.md), подробности перехода — [default-b2-long-v1.md](docs/design/default-b2-long-v1.md)).

## Запуск

Требуются Node.js 20.19+ или 22.12+ и npm. Для настольной сборки нужны Rust stable и [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).

```bash
npm install
npm run dev
# Настольный режим:
npm run tauri dev
```

Адрес Vite обычно `http://localhost:5173`. Обычный запуск в любой сборке (dev, production, Tauri) открывает основную игру; параметры адреса `?rules=`, `?deck=`, `?seed=`, `?economy=` на неё не влияют.

## Правила боя

- **Отряд.** Вариан (Воин, 25 здоровья) и Джайна (Маг, 18 здоровья). Смерть любого героя — поражение и конец похода; ноль здоровья врага — победа. Здоровье переносится между боями, броня и боевые состояния — нет.
- **Ход.** Каждый ход — 4 маны и новая рука из 7 карт; несыгранные карты в конце хода уходят в сброс. Карты обоих героев разыгрываются в любом порядке нажатием (мышь, клавиши 1–9 и 0); Enter завершает ход, кнопка «?» открывает справку.
- **Броня** поглощает урон и исчезает, когда враг закончит свой ход, — даже если по герою не били. Броня «цели» достаётся герою, которого атакует враг; против удара по обоим героям карта спрашивает, кого прикрыть основной защитой. Если в этот ход враг по герою не бьёт, описание карты предупреждает, что её броня сгорит без пользы.
- **Намерение врага** показывает цель, урон и потерю здоровья. Подготовленный удар раскрывает только цель: его сила видна на следующем ходу. Свойства ударов: **бронебой** (игнорирует часть брони), **срыв** (удар отменяется, если за ход отнять у врага указанное количество здоровья; урон по броне врага не в счёт), **метка** (переживший удар герой становится Уязвимым), **ярость** (следующие объявленные удары сильнее). У Рак'Зора на половине здоровья начинается вторая фаза; уже объявленное действие не меняется.
- **Статусы.** Уязвимость врага: следующая наносящая урон карта получает +3. Кровотечение: враг теряет здоровье в начале своего хода, броня его не поглощает. Обморожение («Ледяная хватка»): следующая атака врага слабее на 30% (минимум на 2); «Раскол льда» может потратить его на усиленный удар.
- **Стартовая колода** — 18 карт с восемью источниками брони и картами «Мороз и сталь» (две «Ледяные хватки», два «Раскола льда»); состав — `honestDeck('armor8', true)` в `src/game/honestDecks.ts`.

## Поход

Сектор I «Старые штольни» — десять посещений: девять рядов и босс. На пути 4–5 обычных боёв, необязательная элита, комнаты развития и привал перед боссом. Пути строятся детерминированно из зерна похода (оно показано на карте) и идут слева направо; закрытые узлы показывают только категорию. Кузница, сокровищница и событие до входа выглядят как «неизвестная комната» и раскрываются после посещения.

- Обычная победа — выбор одной карты из трёх или пропуск; элита — одна карта из пяти или личный артефакт (по одному слоту на героя).
- Привал: до 6 здоровья одному герою или улучшение одной карты.
- Кузница, сокровищница и события: улучшение, удаление и замена карт (одно окно с колодой и сравнением «что изменится»), карта или артефакт на выбор, рискованное предложение. Отмена выбора ничего не меняет; посещение заканчивается подтверждением или уходом.

## Сохранения

Поход сохраняется после каждого действия в `localStorage` (`spellwhim.run.v1.honest-b2-long` и резервная копия `.backup`). Прерванный бой при продолжении начинается заново с тем же здоровьем и колодой; ожидающая награда, комната и выбор в ней сохраняются. Повреждённое или несовместимое сохранение не удаляется: его можно повторно загрузить, скачать копией или сознательно заменить новым походом. Слоты прежних режимов игра не читает и не трогает.

## Проверки

```bash
npm test                 # правила, сценарии, интерфейсные модели и эталон 427 боёв
npm run build            # vue-tsc и production-сборка
npm run scenarios -- 42  # сценарии без UI
npm run tauri build      # настольная сборка (нужны системные зависимости Tauri)
```

Сценарии принимают seed и не требуют браузера. Для собственных сценариев используйте `createBattle` с `{ seed, deck, economy }`, `playCard(state, instanceId)` и `endTurn(state)`.

## Лаборатория разработчика (только dev-сборка)

Прежние режимы и исследовательские инструменты сохранены для сравнения и защиты от регрессий и открываются только в dev-сборке по `?dev-rules=` (например `?dev-rules=control`, `?dev-rules=honest-a08`, `?dev-rules=honest-b2&deck=armor6&seed=11`); у каждого режима свой слот сохранений и бейдж «Лаборатория». Скрипты Balance Lab и лабораторий (`npm run balance`, `economy`, `honest-b:lab`, `sector-long:lab`, `challenge:lab` и др.) описаны в [default-b2-long-v1.md](docs/design/default-b2-long-v1.md) и отчётах, на которые он ссылается. Dev-страницы: `card-preview.html` (боевые сцены и рука), `sector-preview.html` (карта и комнаты), `tokens-preview.html` (дизайн-токены).

## Архитектура

- `src/game/types.ts` — шаблоны и экземпляры карт, декларативные эффекты, враги и состояние.
- `src/game/battle.ts` — проверка, оплата, план и однократное разрешение действия; предпросмотр, прогноз врага и конец хода.
- `src/game/economy.ts`, `src/game/rulesMode.ts` — экономики боя и выбор правил запуска (`resolveLaunch`).
- `src/game/campaign.ts`, `src/game/sectorLong.ts`, `src/game/dungeonRooms.ts`, `src/game/runSave.ts` — поход, длинный сектор, комнаты и сохранения.
- `src/ui/` — чистые модели представления (карта, угрозы, карты, операции с колодой) и тексты правил для экранов (`rulesInfo.ts`).
- `src/composables/` — реактивный адаптер боя, анимации по ID действия, клавиатура.
- `src/components/` — экраны и элементы интерфейса; `src/assets/art/` — иллюстрации.
- `src/game/balance.ts`, `balancePlanner.ts`, `honestLab.ts`, `research/mana/` — лаборатории и исследования; в игре не используются.
- `src-tauri/` — оболочка Tauri 2. Проектные инструкции — в `AGENTS.md`.

## Ограничения

Один сектор из трёх задуманных, два героя; нет звука. Часть иллюстраций — временные (см. `ASSET_MANIFEST.md`), у некоторых карт и врагов — заглушки. Классовые эмблемы — внешние SVG Game-icons.net по CC BY 3.0; авторство указано ниже. Сцена и эффекты процедурные, сеть при игре не требуется.
