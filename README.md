# Spellwhim: Сумеречная чаща

Одиночный карточный PvE roguelike-прототип на Vue 3, TypeScript, PixiJS 8 и Tauri 2. Бранн и Лира используют общую колоду и три маны, проходят три боя, сохраняют здоровье между ними и получают карты-награды. Vue рисует интерфейс, PixiJS — боевые эффекты; правила работают отдельно от графики.

## Запуск

Требуются Node.js 20.19+ или 22.12+ и npm. Для настольной сборки нужны Rust stable и [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).

```bash
npm install
npm run dev
# Настольный режим:
npm run tauri dev
```

Адрес Vite обычно `http://localhost:5173`. Нажмите карту, чтобы разыграть её; завершение хода запускает показанную атаку врага. Смерть любого героя означает поражение.

## Боевой интерфейс v0.3

Общий ход отряда явно отделён от розыгрыша карты и атаки противника. Намерение показывает цель, броню и ожидаемую потерю здоровья. Активные связки отмечены возле персонажей и усиливают предпросмотр подходящих карт. Клик или перенос вверх разыгрывает карту; 1–9 выбирают карту, Enter завершает ход, кнопка «?» открывает справку.

[Обзор переработки, проверки, скриншоты и ограничения](docs/combat-ui-v03.md).

## Колода и связки v0.2

Стартовая колода содержит по две копии меча, огненного шара и стойки. У каждой копии свой ID. Каждый ход добираются 3 карты; остаток руки сбрасывается. Когда колода пуста, перемешивается сброс. Сыгранную платную карту после повторного добора можно снова оплатить. Быстрый выпад выбывает до конца боя.

- **Маг → воин:** Огненный шар накладывает метку. Следующий удар Бранна расходует её: +3 урона и добор.
- **Воин → маг:** Стойка и Бастион создают защитный резонанс. Следующее атакующее заклинание Лиры расходует его: +2 урона.
- Оба состояния не суммируются и истекают в конце текущего хода игрока. Подходящие карты подсвечены и показывают фактический бонус.
- Защита прикрывает героя под прицелом. Бастион даёт броню также напарнику; она сохраняется до атаки по владельцу. Между боями щиты и состояния очищаются.

[Правила, обнаруженные проблемы, роли карт, сценарии баланса и следующие задачи](docs/combat-v02.md).

## Проверки и сценарии без UI

```bash
npm test
npm run build
npm run scenarios -- 42
npm run tauri build
```

Сценарии принимают seed и не требуют браузера. Детерминированный RNG, зоны колоды и ожидающий розыгрыш находятся в `BattleState`. Для собственных сценариев используйте `createBattle` с `{ seed, deck, openingHandSize }`, `playCard(state, instanceId)` и `endTurn(state)`. Последняя команда сборки требует системных зависимостей Tauri.

## Архитектура

- `src/game/types.ts` — шаблоны и экземпляры карт, декларативные эффекты, связки, враги и состояние.
- `src/game/battle.ts` — проверка, оплата, план и однократное разрешение действия; расчёт предпросмотра и конец хода.
- `src/game/deck.ts` — seeded RNG, перемешивание, добор и сброс.
- `src/game/scenarios.ts`, `scripts/run-combat-scenarios.mjs` — сценарии без графического интерфейса.
- `src/composables/useBattle.ts` — реактивный адаптер правил и колода похода.
- `src/composables/useBattleAnimation.ts` — Pixi/fallback-события по ID, тайминги и отмена.
- `src/components/` — карта похода, сцена, рука, портреты, награды и PixiJS слой.
- `src/assets/art/` — девять оригинальных AI-иллюстраций и две классовые SVG-эмблемы из Game-icons.net.
- `src-tauri/` — оболочка Tauri 2. Проектные инструкции — в `AGENTS.md`.

## Ограничения

Один маршрут, два героя, шесть шаблонов карт и простой AI с чередованием целей. Нет звука, сохранений, редактора колоды и полной статистической оценки баланса кампании. Иллюстрации сгенерированы ImageGen специально для прототипа. Классовые эмблемы — внешние SVG Game-icons.net по CC BY 3.0; авторство указано ниже. Сцена и эффекты процедурные, шрифты используют локальные fallback, сеть при игре не требуется.
